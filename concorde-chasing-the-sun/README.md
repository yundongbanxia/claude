# 协和 · 逐日　CONCORDE · CHASING THE SUN

> 曾有一架客机，飞得比太阳还快。

一部 **3 分 24 秒**的原创短片，讲述协和超音速客机（1976–2003）的故事：从 1962 年的一张图纸，到 1969 年首飞、突破音障、两倍音速巡航，再到向西飞行时“追上落日”，最后在 2003 年落下帷幕。

**整部片子没有任何外部素材**——没有视频、图片、音频采样，也没有 3D 模型文件。
画面由 Canvas 2D 实时绘制（含一个自己写的软件 3D 渲染器），配乐与音效由 WebAudio 实时合成。

## 分镜

全片 68 小节、80 BPM，**每小节恰好 3 秒**，画面、音乐、音效共用同一条时间线（`js/film.js` 里的 `TL`）。

| 时间 | 章节 | 内容 |
|---|---|---|
| 0:00 | 序章 | 星空、一道地平线光芒：“曾有一架客机，飞得比太阳还快。” |
| 0:06 | 一 · 图纸 | 1962 年英法条约。用 3D 模型的真实轮廓逐笔“画”出三视图、尺寸线、参数表 |
| 0:30 | 二 · 起飞 | 1969 年图卢兹首飞。迎面、侧向跟拍、固定机位飞越、后上方追随四个机位；滑跑、抬轮、离地、收起落架、加力尾焰 |
| 0:54 | 三 · 突破 | 马赫 0.8 → 1 → 2.04。物理正确的声波圆圈堆成“音障之墙”，再展开成马赫锥；音爆；凝结云；加力在马赫 1.7 关闭 |
| 1:24 | 四 · 逐日 | 舷窗与马赫表 → 追着夕阳环绕飞行 → **倒着走的时钟**（伦敦 10:30 起飞，纽约 09:00 降落）→ 飞机穿过落日，标题揭幕 |
| 2:30 | 五 · 航线 | 点阵地球、首批航线、纽约—伦敦 2 小时 52 分 59 秒纪录 |
| 2:54 | 六 · 落日 | 2003 年最后一班商业航班降落希思罗，天黑，星空，一颗远去的光点 |

### 用到的史实

- 1962-11-29 英法签署协议；机长 61.66 m、翼展 25.6 m、全高约 12.2 m；4 台劳斯莱斯/斯奈克玛 Olympus 593 发动机，加力推力每台约 169 kN
- 1969-03-02 001 号在图卢兹首飞（试飞员 André Turcat）；1969-10-01 首次超音速飞行；1970-11-04 达到两倍音速
- 1976-01-21 首批商业航班（伦敦—巴林、巴黎—达喀尔—里约）；1977-11-22 开通纽约航线
- 巡航马赫 2.04（2,179 km/h）、高度约 18,300 m（60,000 ft）；机头蒙皮约 127 °C；加力用到约马赫 1.7，之后无加力超音速巡航
- 1996-02-07 纽约 → 伦敦 2 h 52 min 59 s；2003-10-24 最后一班商业航班；共造 20 架，其中 14 架投入航班
- 伦敦纬度（约 51.5°N）地表随地球自转的线速度约 1,040 km/h，赤道约 1,670 km/h——协和比它快得多，所以向西飞行时当地时间会“倒着走”

## 技术说明

没有构建步骤、没有依赖，纯静态文件。

```
concorde-chasing-the-sun/
├── index.html            播放器页面（开始页、控制条、结束页）
├── js/
│   ├── util.js           数学、缓动、可复现的伪随机、噪声
│   ├── plane.js          协和 3D 模型（程序生成网格）+ 软件光栅渲染器（画家算法、光照、环境反射、边缘光）
│   ├── gfx.js            发光精灵、云、星空、镜头光晕、辉光/暗角/胶片颗粒、排版
│   ├── world.js          天空、地面、跑道、尾焰、高空云海（世界坐标固定的 billboards）、气流线
│   ├── geo.js            手描的粗略大陆轮廓 → 点阵地球
│   ├── film.js           时间线常量 TL、场景注册、字幕/章节/HUD
│   ├── scenes_a…e.js     各幕的绘制代码（纯函数：画面 = f(时间)）
│   ├── audio_engine.js   混音链、卷积混响、乐器与音效合成器
│   ├── audio_score.js    配乐编曲 + 音效时间线 + 播放器（支持拖动进度）
│   └── main.js           播放器逻辑、自适应分辨率、离线渲染钩子
├── fonts/                仅含本片用到字形的字体子集（Noto Serif/Sans SC、Montserrat、JetBrains Mono，均为 SIL OFL）
├── tools/
│   ├── render.mjs        离线渲染 MP4（Playwright + ffmpeg）
│   ├── fetch_fonts.py    重新生成字体子集
│   ├── analyze.py        按小节分析响度，检查削波
│   └── shot.mjs          开发用：把某一时刻截成 PNG
├── dev/                  开发用测试页（单独看飞机模型、单帧调试）
└── video/                成片
```

**画面是时间的纯函数。** 每个场景都是 `draw(ctx, t)`，同一个 `t` 永远得到同一帧：没有累积状态，可以随意拖动进度条，也能逐帧导出视频。

**协和模型。** `plane.js` 用真实尺寸程序生成约 1,400 个面：切线卵形机头（可下垂）、哥特式三角翼、垂尾、4 台并排发动机、可收放起落架、客舱小窗与座舱风挡。用画家算法排序（按“机身上部 / 机翼 / 机腹 / 发动机与起落架”分层，解决大面机翼的错序），再做半球环境光 + 太阳漫反射 + 高光 + 天空反射 + 逆光金边。

**音乐与音效。** 全部实时合成：
- 乐器：毡槌钢琴（PeriodicWave + 动态低通）、铃音（非谐波部分音）、锯齿波弦乐/铺底/铜管、共振峰“啊”合唱、低音、鼓组（底鼓、太鼓、军鼓、镲、各种上升音与冲击）。
- 音效：电传机打字声、喷气发动机（隆隆声 + 咆哮 + 涡轮啸叫 + 加力爆裂，由速度/推力曲线驱动，含多普勒飞越）、音爆（双响 N 波 + 次低频 + 余波）、起落架液压声、触地与轮胎声、无线电静噪、客舱提示音、倒走时钟的“嗒嗒”声……
- 混响用程序生成的脉冲响应，配乐有力度曲线与“闪避”（音爆时压低音乐）。

**同一份代码，两种输出。** 音频引擎既能跑在实时 `AudioContext`，也能跑在 `OfflineAudioContext`（按时间窗口分批创建节点，避免一次性创建几万个节点而渲染极慢）。

### 重新渲染 MP4

```bash
# 需要：Node 18+、Playwright（含 Chromium）、ffmpeg
npm i -g playwright   # 或本地安装，然后 npx playwright install chromium
node tools/render.mjs --out video/concorde-chasing-the-sun.mp4 --fps 30 --width 1920 --workers 4 --crf 20
# 只渲染音轨 / 只做画面：--audio-only / --video-only
python3 tools/analyze.py /tmp/concorde-render/audio.wav   # 看每小节响度
```

### 性能

播放器会根据实际帧率自动在 1080p / 864p / 720p / 540p 之间切换内部渲染分辨率。画面里没有使用 WebGL，所以在没有 GPU 加速的环境里也能运行，只是会降分辨率。
