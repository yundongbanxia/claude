# 生化危机4 重制版 · 村庄篇（同人复刻）

一款在浏览器里运行的越肩视角动作恐怖游戏，复刻《生化危机4 重制版》**村庄章节**的玩法与节奏：
森林小路 → 猎人小屋 → 村庄广场围攻（电锯男、教堂钟声）→ 农场 → 大门终局。

所有模型、贴图、音效和音乐都由代码实时生成，整个游戏就是**一个 HTML 文件**（约 1 MB），
下载后双击就能离线游玩，不需要安装、不需要联网。

> 非官方同人作品，与 CAPCOM 无关，仅供个人学习交流。

## 怎么玩

1. 下载 [`release/RE4-Village.html`](release/RE4-Village.html)（在 GitHub 页面点 *Download raw file*）。
2. 用 **Chrome / Edge**（推荐）或 Firefox 打开。
3. 点击画面锁定鼠标，建议戴耳机（3D 音效：电锯声从哪边来很重要）。

> 帧率低的话，在「设置」里把画质调到「低」。

## 战斗要点（和原作一样）

- **爆头** → 敌人捂脸硬直；**打腿** → 敌人跪地。这时靠近按 **F**：回旋踢（范围击倒）/ 从背后背摔。
- 敌人**挥下武器的瞬间**按 **Q** = 完美格挡（不耗耐久），按住 **Q** = 普通格挡（耗小刀耐久），飞来的斧头也能弹开。
- 倒地的敌人按 **Q** 补刀；没发现你的敌人从背后按 **Q** 潜行击杀。
- 射击敌人手里**点燃的炸药**会直接在他身边爆炸。飞来的斧头和镰刀可以打下来。
- **电锯男（萨尔瓦多医生）**被他抓住就是一击毙命。保持距离，闪光弹、手雷、霰弹枪近距离都能放倒他。
- 围攻时可以躲进两层的房子：**推书架堵门**、**推倒梯子**把爬上来的村民摔下去，也可以跳窗逃跑。
- 敌人会掉落你**缺少的东西**（弹药快没了多掉弹药，血少了多掉草药）。难度会根据你的表现暗中调整。
- 蓝火旁的**商人**：买卖、改造武器、修小刀、用尖晶石交换；**打字机**可以存档。
- 农场里有 5 个**蓝色徽章**，全部打碎后可以找商人领奖励。

## 内容

- 3 个区域：森林小路（含猎人小屋）、村庄、农场，初次通关约 30–40 分钟
- 敌人：村民（镰刀/斧头/空手扑抓）、草叉村民、女村民、飞斧投掷者、炸药投掷者、火把村民、电锯男
- 武器：SG-09 R、Red9、W-870 霰弹枪、SR M1903 步枪（瞄准镜、贯穿）、手雷、闪光弹、战斗小刀
- 系统：部位伤害与硬直、体术、格挡、隐藏动态难度、手提箱网格背包（拖动/旋转/草药合成/制作）、
  商人（购买/出售/改造/修理/交易）、打字机存档（3 个槽位）+ 自动检查点、4 档难度
- 程序生成的一切：低多边形骨骼角色、Canvas 贴图、WebAudio 合成音效与动态配乐、可选的浏览器西班牙语语音喊话

## 开发

```bash
npm install
npm run dev        # 本地开发 http://localhost:5173
npm run build      # 生成 dist/index.html（单文件）
npm run release    # 构建并复制到 release/RE4-Village.html
npm test           # 单元测试（Vitest）
npm run e2e        # 浏览器冒烟测试（Playwright，需先 build）
```

调试参数：
- `?area=test&enemies=3` 直接进入测试场地；`?area=village` / `?area=farm` 直接进入某个区域
- `?debug=god` 无敌 + 帧率显示；`?diff=hardcore` 指定难度

代码结构：

```
src/
  anim/     低模骨骼角色（单个 SkinnedMesh）、关键帧动画、动作数据
  audio/    WebAudio 合成音效、电锯/火焰循环、教堂钟声、动态配乐
  core/     数学、随机数、输入
  data/     武器 / 物品 / 难度数值
  game/     玩家、敌人 AI、导航调度、战斗结算、动态难度、背包、实体
  levels/   森林、村庄、农场以及公用场景件
  render/   渲染器与后期、程序贴图、粒子与贴花
  ui/       HUD、菜单、手提箱、商人
  world/    地形、碰撞、多层导航网格（流场寻路）、场景道具生成
```
