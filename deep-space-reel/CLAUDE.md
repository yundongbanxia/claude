# CLAUDE.md — 《人类的深空之旅》视觉规范

这是一支 30 秒的 Remotion 动态图形短片（1920×1080 · 30fps · 900 帧）。
**之后的任何修改都必须遵守本文件。** 规范与代码冲突时，以本文件为准，并同步更新 `src/theme.ts`。

开工前先读 `.claude/skills/remotion-best-practices/`（Remotion 官方 Agent Skills）。

---

## 1. 基调

冷静、克制、电影感。像一台在深空里安静工作的仪器，而不是一张海报。

- 画面永远只有一个视觉焦点。
- 信息是"标注"出来的，不是"喊"出来的：HUD 细线 + 小号等宽字。
- **禁止**：霓虹、赛博朋克、扫描线、故障效果（glitch）、发光叠加（text-shadow / box-shadow 发光 / bloom）、镜头光晕、粒子爆炸、弹跳动画、emoji。

## 2. 配色（背景 + 3 色，不得新增）

| Token | 值 | 用途 |
|---|---|---|
| `COLOR.space` | `#04060A` | 背景。深空黑，略偏冷 |
| `COLOR.white` | `#E4E9EF` | 冷白：正文、细线、星点、HUD |
| `COLOR.gold` | `#CBB682` | 淡金：关键数字、里程碑、轨迹、强调细线 |
| `COLOR.rust` | `#B4552F` | 火星锈红：**只**用于火星相关元素 |

- 层级靠**透明度**区分，不靠新颜色：`ALPHA.faint .14 / line .28 / muted .55 / text .92`。
- 一帧里淡金不超过 3 处，锈红只在火星出现时使用（第 01 章的火星轨道和光日标尺上的火星时延是"预告"，允许）。
- 渐变只允许两处：边缘暗角（Vignette）与光日信号脉冲的拖尾。

## 3. 字体

| 用途 | 字体 | 字重 | 字号 |
|---|---|---|---|
| 中文标题 | Noto Serif SC | 300 | 56–112px，字距 0.2–0.32em |
| 中文小字（≤24px） | Noto Serif SC | 400 | 17–24px（300 在视频压缩后会糊） |
| 大号数字 | IBM Plex Mono | 200 | 34–92px，`tabular-nums` |
| 英文 / HUD 标签 | IBM Plex Mono | 300 | 14–22px，字距 0.16–0.46em，全大写 |

- 中文只用衬线，英文和数字只用细体等宽。不混用第三种字体。
- 字距加大后要用 `marginRight: -<字距>` 抵消尾部空白，保证居中。
- Noto Serif SC 是**本地子集**（`public/fonts/`），只包含 `src/` 里出现过的字符。
  **改动任何中文文案后必须运行 `npm run fonts`**（代理环境下：`NODE_USE_ENV_PROXY=1 npm run fonts`），否则新字会缺字。
- IBM Plex Mono 同样本地化（latin 子集，200/300/400）。**渲染时不得访问任何字体 CDN**：无头 Chrome 不一定信任代理证书，且离线可复现。
- 等宽字体栈的回退是 Noto 子集——但不要依赖它，**中文不要写进 mono 样式**。

## 4. 时间曲线（`EASE`）

| 名称 | 曲线 | 用于 |
|---|---|---|
| `reveal` | `bezier(0.16, 1, 0.3, 1)` | 文字、细线出现：快起、长收 |
| `camera` | `bezier(0.65, 0, 0.35, 1)` | 镜头推拉、物体行进、转场：对称慢进慢出 |
| `exit` | `bezier(0.7, 0, 0.84, 0)` | 退场：加速离开 |
| `linear` | 线性 | 连续漂移（星场、推镜） |

- **不使用**带回弹的 spring、不允许 overshoot。
- 时长：文字出现 24–36 帧；细线绘制 30–50 帧；同屏元素错开 6–12 帧；可读文字至少停留 45 帧。
- 所有动画由 `useCurrentFrame()` + `interpolate()` 驱动，默认 `CLAMP`。禁止 CSS transition/animation、禁止 R3F `useFrame()`。

## 5. 镜头语言

- **镜头永远在动，但永远很慢。** 平面场景每场推近 2–4%（线性）；旅行者场景为"拉远"（1.5 → 0.78，`camera` 曲线），火星为"推近"（距离 5.8 → 5.05）。
- **视差星场**贯穿全片、跨越所有转场不重置：3 层，横向漂移速度比约 1 : 2.5 : 6，推近幅度 2% / 5% / 10%。
- 转场只用 20 帧溶解（`fade` + `camera` 曲线）。不用划像、滑动、翻转、硬切闪白。
- 不用抖动、急推（zoom punch）、甩镜（whip pan）、运动模糊拖影。
- 3D 火星：自转方向为顺行（地表特征从左向右移动），光源在左上前方，晨昏线落在右侧。

## 6. HUD 标注

- 线宽 1px；四角注册标记、底部进度细线、时间码 `T+mm:ss:ff`、章节号。HUD 全片常驻、很安静。
- 标注 = 上行等宽英文/数字 + 下行衬线中文（`<Label>`）。
- 引线：从目标出发，折线（elbow）到标签，标签左对齐于统一的 x。标签不压在轨迹或其他标签上——改版面后先做几何检查。
- 可读内容在安全区内：左右 ≥140px，上下 ≥110px。

## 7. 数据

- 屏幕上的每一个数字/日期都来自 `src/data/facts.ts`，并在 `README.md → 数据与来源` 里有来源行和链接。
- 新增数字：先联网核实 → 写进 README → 再写进 facts.ts。**拿不准的数字宁可不用。**
- 示意性质的图形（对数距离尺度、轨迹走向、行星位置、火星地表纹理）必须在画面上注明"示意"，不得暗示为真实数据。
- 日期有时区歧义时只写年份（例：水手4号 1965）。

## 8. 分镜（900 帧）

| 场景 | 帧长 | 主体地址 |
|---|---|---|
| 00 序 `Prologue` | 150 | 细线展开，标题落定 |
| 01 远航 `VoyagerScene` | 290 | 对数尺度日心示意图：1977 发射 → 木星 → 土星 → 1990 回望 → 2012 日球层顶；镜头拉远 |
| 01b 光日 `LightDayScene` | 180 | 一把 24 小时的标尺：信号脉冲从地球走到旅行者1号；地火时延只占左端一小截 |
| 02 火星 `MarsScene` | 270 | 3D 火星推近自转，左侧里程碑逐条出现，三个着陆点投影标注 |
| 03 未完 `Outro` | 90 | "信号，仍在路上"，淡出到黑 |

相邻场景重叠 20 帧溶解：150+290+180+270+90 − 4×20 = 900。时长常量在 `src/theme.ts`（`SCENE`、`TRANSITION`），改一处全片同步。

## 9. 工程约定

- 场景各自一个文件，并在 `Root.tsx` 的 `Scenes` 文件夹里以同一组件引用注册（connected compositions），可单独预览。
- 3D 内容包在 `<ThreeCanvas>` 里；其中的 `<Sequence>` 必须 `layout="none"`。
- 火星纹理为程序化生成（种子噪声，确定性），不引用外部贴图。
- 提交前：`npm run lint`（eslint + tsc）。
